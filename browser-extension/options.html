Zimmer Quick Router

Drop a pin on any page, type what you noticed, and a Zimmer agent session picks it up with the page and the pin. You never leave the page.

The instance this browser can reach — on the tailnet, that is its tailnet address. Saving asks Chrome for permission to talk to that one origin.

Mint one on Settings → API keys in Zimmer and choose Quick Router only. That key starts Quick Router sessions and can read nothing — a full-API key is refused here.

How it works
  1. On any page, click the toolbar icon or press Alt+Shift+Z.
  2. Click the thing your feedback is about. Enter skips the pin; Esc cancels.
  3. Type, then ⌘/Ctrl+Enter. A toast links to the session Zimmer started.

What is sent: your message, the page URL and title, the page reduced to markdown (capped at 20,000 characters), and — for the pin — the element under it, a selector for it, its text, and the content around it. All of it lands in the session's prompt, so mind what page you are on.
